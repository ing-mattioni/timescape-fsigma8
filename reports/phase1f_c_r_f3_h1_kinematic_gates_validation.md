# Review finding F3: validating the H1 background-identity and CLK-H1 gates

## 1. Purpose, authorisation and checkpoint

This change addresses finding **F3** of
`phase1f_c_r_post_remediation_independent_audit.md`, "The H1 realization's
'conditional closure' is not demonstrated". The review found two gaps:
- **J_Ξ was not gated.** The clock mismatch was computed and returned but
  never checked. On the only clock branch the runtime implements (`CLK-H1`),
  no source for it exists.
- **No background identity was checked.** None of the zeroth-order identities
  of the two-region dust background were validated. The only
  continuum-derived manufactured state that the 1E-G phase cites as evidence
  violates them.

The review suggested three remedies:
1. add fail-closed gates for `J_Ξ = 0` and for the background identities, with
   `K_D` as an explicit input;
2. exhibit a state that satisfies all of them;
3. or downgrade the status tokens.

- **Authorisation.** The human request was "fix F3 by adding the J_Ξ=0 and
  background-identity gates". This change adds validation gates, one explicit
  input (`K_D`) and one explicit policy.
  - It changes no equation of arXiv:2511.17160v2 ([GM]).
  - It changes no Phase 1E-F/1E-G transfer or constitutive formula.
  - It changes no existing tolerance.
- **Parent checkpoint:** `fb1705a6899d19ad76dd866629b73a2f4091995b`. The
  artifact was generated on this change's working tree over that parent.
- **Runtime of the recorded artifact:** Python 3.13.12, numpy 2.5.3,
  scipy 1.18.1, Linux x86_64.
- **Artifact:**
  `artifacts/independent/phase1f_c_r_f3_h1_kinematic_gates_validation.json`
  (git-ignored). It is regenerated by `scripts/validate_h1_kinematic_gates.py`,
  which uses only the independent package and exits nonzero if any gate
  fails.

The frozen review report and its inventory are not edited. They still record
F3 as `OPEN` at `4746386`. §10 gives F3's status after this change.

## 2. Design

### 2.1 The gate policy (mandatory, no default)

`H1Configuration` gains two mandatory fields: `J_Xi_tolerance` and
`kinematic_gate_policy: H1KinematicGatePolicy`. The policy has two values:

| Policy | What it does | `scientific_status` of the result |
|---|---|---|
| `ENFORCE` (`"ENFORCE_TWO_REGION_BACKGROUND_AND_CLK_H1_KINEMATICS"`) | fails closed on every background identity and on `J_Ξ` | `CONDITIONALLY_CLOSED` (1E-F); the 1E-G bridge result is `CONDITIONALLY_DERIVED_CONTINUUM_REALIZATION` |
| `ALGEBRAIC_VALIDATION_ONLY` | evaluates and records the same residuals without enforcing them | `ALGEBRAIC_VALIDATION_ONLY` for both |

Under this contract, a status token that asserts closure can be emitted only
by a run that passed every kinematic gate. That is the downgrade F3 asked for,
applied to every unenforced result.

The value `ALGEBRAIC_VALIDATION_ONLY` is the same token that Phase 1F-C-R
already assigns to manufactured H1 trajectories
(`scientific_status.MANUFACTURED_H1_TRAJECTORIES`). A raw string in place of
the enum is refused.

The frozen 1E-F/1E-G operator-algebra tests keep their fixtures unchanged
and run under `ALGEBRAIC_VALIDATION_ONLY`. Those fixtures test:
- operator derivatives, transmission jumps and provenance roundtrips;
- the `R_Z`/`R_eff` term algebra;
- the nondegeneracy guards.

Their backgrounds are deliberately not kinematically consistent (e.g.
`Θ_r = H_r = 0` with `ρ_r = 1`), and their results are now labelled that way.

### 2.2 Explicit `K_D`

`H1Background` gains the mandatory field `six_K_D_over_a_D_squared`
(`6K_D/a_D²` at the evaluation time). It is the constant-curvature part of
`W_D = ⟨R⟩_D − 6K_D/a_D²` ([GM] Eq. (3.12); Phase 1E-D §19). GM Timescape
uses `K_D = 0`. Its jet follows from two facts:
- `K_D` is constant;
- `d ln a_D/dt = Θ/3`.

### 2.3 The gated background identities

`two_region_background_identity_residuals(background)` returns, for each
identity, the largest absolute residual over the jet orders the supplied jets
determine:
- three orders for algebraic identities;
- two orders for evolution equations.

Under `ENFORCE` each residual must be at most the existing
`background_identity_tolerance`, and they are checked in the order below.

| # | Name | Identity | Source | Orders |
|---|---|---|---|---|
| 1–2 | `regional_hamiltonian_constraint_r` | `R̄_r = 16πGρ_r − (2/3)Θ_r²` | [GM] (2.13) at zeroth order, Λ = 0 | 0–2 |
| 3–4 | `regional_raychaudhuri_r` | `Θ̇_r = −α_r(Θ_r²/3 + 4πGρ_r)` | [GM] (2.12) with the standard −Λ, Λ = 0 | 0–1 |
| 5–6 | `regional_dust_continuity_r` | `ρ̇_r = −α_rΘ_rρ_r` | `ρ_r a_r³` constant | 0–1 |
| 7 | `partition_kinematics` | `ḟ_v = f_vf_w(Ξ_v − Ξ_w)` | 1E-D §17 (H-D5) | 0–1 |
| 8 | `average_expansion` | `Θ = f_wΞ_w + f_vΞ_v` | 1E-D §17 | 0–2 |
| 9 | `two_region_backreaction` | `Q̄ = (2/3)f_vf_w(Θ_v − Θ_w)²` | 1E-D §18 (H-D7); its first variation is the implemented `A_Q`, `B_Q` | 0–2 |
| 10 | `averaged_curvature_W` | `W̄ = f_wR̄_w + f_vR̄_v − 6K_D/a_D²` | [GM] (3.12); `K_D` explicit | 0–2 |
| 11 | `averaged_hamiltonian_constraint` | `Θ²/3 = 8πGρ_d − (⟨R⟩_D + Q̄)/2` | [GM] (3.8), Λ = 0 | 0–2 |

| 13 | `averaged_mass_conservation` | `ρ̇_d = −Θρ_d` | [GM] (3.10) | 0–1 |

Rows 1–2, 5–10 are the review's list. Three kinds of rows go further, and
each is required by the model the runtime already uses:
- **Rows 3–4, the regional Raychaudhuri equation.** The runtime asserts
  exact regional dust-FLRW backgrounds, and `H_r.first` enters the regional
  `Z_r` evolution. Without this gate, `H_r.first` would be unconstrained.
- **Rows 11–13, GM's own averaged equations.** The runtime's effective fluid
  ([GM] (3.12)–(3.13)) and target equations ([GM] (4.21)–(4.23)) presuppose
  them.
- **Row 13 in particular.** It catches a mass-weighted mismatch between `Ξ_r`
  and `α_rΘ_r`, which the other rows allow.

Unchanged points:
- `Θ_r = 3H_r` stays gated under both policies.
- The 1E-G bridge's `Ξ_r = α_rΘ_r` branch check stays gated under both
  policies.
- The existing nondegeneracy gates still act first.

### 2.4 The `J_Ξ` gate

`J_Ξ = [Ḟ_v − A_f F_v − f_vf_w E_ΔΞ,0 − J_f]/(f_vf_w)` is the residual of the
linearised partition kinematics. It is the part of `L_D(δΞ_v − δΞ_w)` that
the supplied clock input does not account for.

`CLK-H1` (Phase 1E-E §11) has:
- a homogeneous rate;
- spatial dependence `EXCLUDED`;
- a perturbative lapse `NOT_DEFINED`.

So a clock mismatch has no admissible source there. Under `ENFORCE`,
`max|J_Ξ| ≤ J_Xi_tolerance` is required. The check runs after the clean
residual gates, so existing `R_Z`/`R_eff` failures keep their own errors.
Results record the following:
- `kinematic_gate_policy`;
- `clock_branch = "CLK-H1"`;
- `background_identity_residuals`;
- `J_Xi_max_abs`.

### 2.5 A consistent-background constructor

`two_region_dust_flrw_background(...)` builds the background jets of two exact
dust-FLRW regions at one instant. Its free data are the instantaneous values
of:
- `f_v`, `ρ_r` and `H_r`;
- the clock jets `α_r`;
- `6K_D/a_D²` and `G`.

It uses the homogeneous-clock branch `Ξ_r = α_rΘ_r` (Phase 1E-G §18).
Identities 1–10 hold by construction. Identities 11–13 then hold if and only
if the clock data are compatible with them (§5.3). This is a validation
constructor for one instant, not a trajectory.

## 5. Background results

### 5.1 The constructor and detection (K1, K2)

**K1.** The constructor satisfies all 13 identities to `≤ 3.6e−15`. This holds
for:
- `f_v` from 0.15 to 0.85;
- `K_D/a_D² ∈ {0, 0.3, −0.7}`;
- `G ∈ {1/4π, 0.37}`.

The tests also check its jets against independent closed forms of
proper-time dust FLRW: `Ḣ = −H² − 4πGρ/3`, `ρ̇ = −3Hρ`, and `Ḧ`.

**K2.** A shift of `ε = 1e−3` in one input jet produces exactly the predicted
residual in the targeted identity, to relative error `≤ 7.8e−13`:
- `R̄_r`, `ρ̈_r`, `f̈_v`, `Θ̈`, `Q̈̄`, `W̄` each give `ε`;
- a shift of `Θ̈_r` with `Ḧ_r` moved alongside, so that `Θ_r = 3H_r` still
  holds, gives `ε`;
- `Q̄ → Q̄ + ε` gives `ε/2` in [GM] (3.8) and `ε` in [GM] (3.9).

A clock shift `Ξ_w → Ξ_w + ε` is compensated at the value order in the
partition and average-expansion identities. [GM] (3.10) still sees the
mass-weighted mismatch `f_wρ_wε = 9.0e−4`, and the measured value is
`9.0e−4`.

### 5.2 `K_D` enters only `W̄`

For a background built with `6K_D/a_D² = 0.3`, declaring `0.0` instead
changes only `averaged_curvature_W`. The residual is exactly the `K_D` jet.
All other identities stay at roundoff, because [GM] (3.8) is written with
`⟨R⟩_D`.

### 5.3 Unequal regional clocks (K3): a new observation

With identities 1–10 satisfied, the value order of [GM] (3.8) reduces
algebraically to

```text
Θ²/3 − 8πGρ_d + (⟨R⟩_D + Q̄)/2 = [Θ² − (f_wΘ_w + f_vΘ_v)²]/3 .
```

Here `Θ = Σ f_r α_r Θ_r` on the constructor's branch.

The two-region backreaction is built from the proper regional rates `Θ_r`
(1E-D H-D7, and the implemented `A_Q`, `B_Q`). It is consistent with GM's
averaged Hamiltonian constraint only if `Σ f_r α_r Θ_r = Σ f_r Θ_r`. That
holds for common proper time (`α_r = 1`) or a specially balanced pair of
clocks.

| `α_w` | Identities 1–10 | [GM] (3.8) | [GM] (3.9) | [GM] (3.10) | Value-order prediction |
|---|---|---|---|---|---|
| 0.90 | `2e−16` | `3.87e−1` | `2.08e−1` | `4e−16` | `4.01e−2` |
| 0.95 | `0` | `2.12e−1` | `1.08e−1` | `2e−16` | `2.03e−2` |
| 1.00 | `1e−17` | `4e−16` | `1e−16` | `2e−16` | `0` |
| 1.05 | `2e−16` | `2.52e−1` | `1.14e−1` | `2e−16` | `2.08e−2` |
| 1.10 | `4e−16` | `5.47e−1` | `2.36e−1` | `4e−16` | `4.20e−2` |

The (3.8) and (3.9) columns are maxima over jet orders. The last column is
the value order.

**Consequence.** On the enforced path, unequal regional clocks are admitted
only when they are compatible with GM's averaged equations at that instant.
With `α_r ≠ 1`, the runtime would need a lapse-generalised averaged scheme,
which it does not have. That is the existing open closure
`REGIONAL_COMMON_TIMESCAPE_BACKGROUND_EMBEDDING = NOT_DERIVED`. The gates make
it fail closed instead of silent. They change no model equation.

### 6.2 1E-F contract: a state passing every gate (K5)

In the 1E-F operator contract, the effective-sector inputs `E_ΔΘ` and
`E_ΔΞ,0` are free caller data. On a consistent background (`α_r = 1`), they
can be solved in order:
- `E_ΔΘ` first jet from `R_eff = 0`;
- then its second jet from `R_Z = 0`;
- then `E_ΔΞ,0` from `J_Ξ = 0`.

All three are affine and componentwise.

The resulting state passes every enforced gate:
- the maximum gated residual is `4.4e−16`;
- the status is `CONDITIONALLY_CLOSED`;
- the fields are nontrivial: `max|Δ_d| = 0.046`, `|Z| = 0.077`,
  `|Δ_eff| = 0.061`, `|F_v| = 0.082`.

This holds for both `K_D = 0` and `K_D = 0.3`.

A shift `δ` of the clock input changes `J_Ξ` by exactly `−δ`, to `1.4e−17`,
and leaves `R_Z`, `R_eff` and `C_P` at roundoff. Only the new gate catches
it, and `ENFORCE` raises `J_Xi=…`. The same state evaluated unenforced is
labelled `ALGEBRAIC_VALIDATION_ONLY`.

Because the 1E-F inputs are free, this existence result is expected. The
continuum case below is the informative one.

### 6.3 1E-G continuum: the gated residual map (K6, K7)

In the continuum bridge, `E_ΔΘ` and `E_ΔΞ,0` are derived from the regional
state, so `R_Z`, `R_eff` and `J_Ξ` are genuine constraints. They are linear in
the bulk state `(Δ_w, Z_w, Δ_v, Z_v)`. The study measures the rank of their
stacked residual map.

**Setup.**
- Carrier: 6×3×3, layered, one wall cell.
- Background: consistent, with `f_v = 0.6`, `ρ = (1.5, 0.5)`,
  `H = (0.3, 0.5)` and `α_r = 1`.
- Relative singular values: null `≤ 1e−12`, nonzero `≥ 1e−6`.

| Geometry | `6K_D/a_D²` | rank `[R_Z]` | rank `[R_Z; R_eff]` | rank `[R_Z; R_eff; J_Ξ]` | Instantaneous closed states |

| flat wall and void | 0 | 1 | 2 | 2 | a 2-parameter family |

**Flat geometry (K6).** The least-squares null vector passes every enforced
gate:
- the maximum gated residual is `≤ 4.7e−15`;
- the bridge status is `CONDITIONALLY_DERIVED_CONTINUUM_REALIZATION` and the

At `K_D = 0` the fields are clearly nontrivial:

| Field | `max|·|` |
|---|---|
| `Δ_d` | 0.052 |
| `Z` | 0.158 |
| `Δ_eff` | 0.179 |

At `K_D = 0.3` the closed state has `Δ_d = 0.0104`, `Δ_eff = 0.0166` and

Two further observations, made with the tests and the study prototype:
- A state in the `R_Z = R_eff = 0` plane but orthogonal to the closed line
  fails only at `J_Ξ`. So at `K_D ≠ 0`, the new gate is the binding one.
- For `K_D ≠ 0`, `Z = 0` held in all six parameter sets probed
  (`K_D ∈ {0.1, 0.3, −0.5}` × two backgrounds), to `≤ 5e−15`.

This is a numerical observation, not a derived identity. It suggests that, on
the `R_Z = R_eff = 0` plane, `J_Ξ` is proportional to `K_D·Z`.

In the flat case every transferred field is proportional to one carrier
pattern. Because `χ_w + χ_v = 1`, the mean-zero projections of the two
regional indicator sources are negatives of each other. Each gated field
therefore gives one scalar condition.

**Heterogeneous void geometry (K7).** The wall and void transfers are no
longer collinear, and `R_Z = R_eff = 0` already have rank 4. No nontrivial
bulk state satisfies the clean residual gates, even before `J_Ξ`. The enforced
evaluation of the best least-squares state fails closed at `R_Z`.

## 10. Status of F3 and remaining open points

**Status:** `ADDRESSED_BY_ENFORCED_GATES`.
- `CONDITIONALLY_CLOSED` and `CONDITIONALLY_DERIVED_CONTINUUM_REALIZATION` are
  now emitted only for states that satisfy the background kinematics and
  `J_Ξ = 0`.
- Such states exist at an instant for the 1E-F contract and for flat
  continuum geometries.

Open points for human decision (none is resolved here):
1. **Heterogeneous regional geometry.** For the tested non-flat void
   geometry, only the trivial state satisfies `R_Z = R_eff = 0` on a
   consistent background. Continuum closure has therefore been demonstrated
   only for flat geometries. The 1E-G heterogeneous-geometry and morphology
   comparators (1-D/2-D) never formed Phase 1E-F constitutive quantities, so
   closure had not been tested for them before.
2. **Unequal regional clocks.** With the `Θ_r`-based two-region
   backreaction, [GM] (3.8) admits `α_r ≠ 1` only if
   `Σ f_r α_r Θ_r = Σ f_r Θ_r`. A physical wall/void clock split needs a
   lapse-generalised averaged scheme (§5.3).
3. **The `K_D ≠ 0` observation.** In the flat continuum, `J_Ξ` became an
   independent constraint and forced `Z = 0` in every probe. This is a
   numerical observation awaiting an analytic account.
4. **Time evolution.** No claim is made about whether the gated conditions
   are preserved in time.

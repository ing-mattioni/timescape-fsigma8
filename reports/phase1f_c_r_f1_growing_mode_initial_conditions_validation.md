## 2. The defect being addressed

The paper's dust initial conditions at `t_i` have two parts:
- the flat-ΛCDM growing-mode amplitude `Δ_d(t_i)` from the `qplus` recipe;
- a *ΛCDM* growing-mode rate `−Z_i/Δ_d,i`. This is `54.0106`
  (`upstream_unconverted`) or `49.7107` (`lcdm_to_timescape_converted`) in the
  solver's inverse-time unit.

On the tracker background, the regular solution of the same frozen equations
has a rate of about `40.09` at `0.218 Gyr`. The legacy rate therefore adds
the decaying solution to the growing one. The decaying solution is not
negligible by `t0`: it inflates `Δ_d(t0)` by up to about 14%. It also makes
the rate-unit and epoch "conventions" look like physical choices, when they
mostly measure how much decaying transient each one injects.

## 3. Derivation (logarithmic-rate form of the frozen systems)

Use `s = ln t`. Along a solution with `Δ_d ≠ 0`, define:
- `u := t d ln Δ_d/dt = −tZ/Δ_d`, using `Z = −dΔ_d/dt` from [GM] (4.21);
- `q := Δ_eff/Δ_d` (comoving system only).

The dimensionless background coefficients are:
- `T := tΘ`;
- `A := t²·4πGρ_d`;
- `B := t²·4πGρ_eff`;
- `w := w_eff`.

Each is evaluated with the same Phase 1B functions that the frozen RHS
functions use. Substituting [GM] (4.21)–(4.23) gives

```text
du/ds = u − u² − (2/3) T u + A + B q
dq/ds = (1 + w) u + w T q − q u
```

[GM] (4.27) gives the Mészáros equation `du/ds = u − u² − (2/3) T u + A`.

**The EdS limit.** As `f_v → 0`, the coefficients tend to `T → 2`,
`A → 2/3`, `B → 0` and `w → −1/2`. In that limit:
- the fixed point with `u > 0` is `u* = 2/3`;
- the comoving ratio is `q* = (1+w)u*/(u* − wT) = 1/5`;
- the linearisation has the double eigenvalue `−5/3` in `s`.

So every departure from the regular solution decays as `t^(−5/3)` relative
to it. This covers both the decaying dust mode and the homogeneous `Δ_eff`
mode. The EdS attractor is therefore the unique regular (growing) solution.

**The integration.** Start from `(u*, q*)` at `t_start = start_fraction·t_i`
and integrate forward in `s`. An `O(ε)` offset at the start is damped by
`start_fraction^(5/3)`, which is about `1e−10` for the reference
`start_fraction = 1e−6`. The start is refused (fail-closed) unless each of
`T, A, B, w` is within `eds_limit_tolerance` of its EdS limit.

**The growing-mode ICs:**
- `Δ_d(t_i)` is the unchanged recipe amplitude, bit-identical to the legacy
  conventions;
- `Z(t_i) = −(u(t_i)/t_i)·Δ_d(t_i)`;
- comoving: `Δ_eff(t_i) = q(t_i)·Δ_d(t_i)`, in place of the paper's
  `Δ_eff(t_i) = 0`;
- Mészáros: `Δ_eff` is not part of the state. The field is set to `0.0` only
  because the record requires it, and it is never used.

**Scope.** The result is scale-independent, so it is defined only for the
two clean systems. The barotropic closure ([GM] (4.13)–(4.17)) is rejected
fail-closed at every entry point, for two reasons:
- its early-time solution depends on `k` and on the D3 branch;
- with the corrected negative `c²_s,eff`, it has an exponentially growing
  gradient mode.

A unique regular growing mode therefore does not exist there without new
modelling, which this change does not introduce.

| DOP853 (`1e−13`/`1e−15`) | `1.21e−12` | `2.86e−13` |

The observed spreads match the expected start error. Starting from the EdS
fixed point is wrong by roughly the coefficient deviation at `t_start`, which
grows about linearly in `t`: it is `5.3e−6` at `1e−4·t_i` and `5.3e−8` at
`1e−6·t_i`. That error is then damped by `start_fraction^(5/3)`. For
`start_fraction = 1e−4` this gives about `5.3e−6 × 2.2e−7 ≈ 1e−12`,
consistent with the measured `≤ 2.7e−12`. The residual spreads are therefore
at integrator round-off.

**G3 (independent route).** The frozen *linear* RHS functions (not the
logarithmic-rate system) were integrated from the deep EdS era:
- start time `t_far = 1e−4·t_first`;
- start state `(Δ_d, Z, Δ_eff) = (t^(2/3), −(2/3)t^(−1/3), 0.2 t^(2/3))`
  (Mészáros: `(t^(2/3), (2/3)t^(−1/3))`).

Their `u` and `q` agree with the logarithmic-rate integration to
`1.58e−12` (Mészáros) and `2.92e−13` / `6.69e−13` (comoving `u` / `q`). The
Riccati reduction is therefore equivalent to the frozen equations.

**G4 (trajectories).** Both runs use the notebook preset, start at
0.218 Gyr and use the frozen linear RHS.

| System | Growing ICs: max \|u − u_regular\| over `[t_i, t0]` | Legacy ICs: \|Δu\| at `t_i` | Legacy ICs: \|Δu\| at `t0` |
|---|---|---|---|
| Mészáros | `8.6e−13` | `0.2312` | `2.4e−4` |
| comoving | `3.1e−13` | `0.2273` | `1.7e−4` |

The growing-mode ICs stay on the regular solution to round-off. The legacy
ICs start about 35% away in `u` and relax towards it as `t^(−5/3)`. That
relaxation is the decaying-mode transient identified by F1.

## 11. Tests and scientific status

`tests/test_growing_mode_initial_conditions.py` contains 21 tests. Where
AGENTS.md rule 5 asks for published reference values, none exist: the paper
does not publish the tracker growing-mode rate. The review's independently
derived values and the analytic EdS limit take their place.

The tests cover the following, with tolerances stated in A06-style comments:
- **Reference values.** Four `(epoch, system)` rates (abs `5e−5`) and
  `q = 0.20005` (abs `5e−6`).
- **Amplitude.** `Δ_d(t_i)` is identical to the legacy conventions.
- **Independent route.** The logarithmic-rate integration agrees with the
  far-past linear solution (`1e−9`).
- **Decaying mode.** There is no decaying admixture. The legacy
  `Δ_d(t0)` excess of `1.1312` is reproduced.
- **Limiting case.** The EdS limit is recovered at `f_v0 = 1e−7`.
- **Units and dimensions.** The result is invariant under time-unit
  rescaling (×13.7) and under a change of `G`, and `Z` scales with the rate.
- **Numerics.** The start fraction converges, and the EdS guard fires at
  `start_fraction = 0.5`.
- **Fail-closed paths.** Refused are the mismatched state vector,
  `InitialConditionScenario`, `BarotropicScenario`, the barotropic
  `GrowthScenario`, and a raw-string system.
- **No defaults** in any new signature. The config and the time grid are
  validated.
- **Pipeline.** `f_bare = 3u/(tΘ)` holds (`1e−9`), and the `f_bare(t0)` values
  are pinned. The metadata is JSON-safe.
- **Candidate A.** `G = 6.164012`, independent of the epoch (relative `1e−9`).

**Suite results:**
- before this change: 653 passed, 1 skipped;
- with this change: 674 passed, 1 skipped on Python 3.13.12 and on
  Python 3.11.15.

**Status of F1.** `ADDRESSED_BY_EXPLICIT_OPTION`. The convention
`TIMESCAPE_REGULAR_GROWING_MODE` is available for the Mészáros and comoving
systems, is validated, and is never defaulted. It meets the 1D-A §6
requirement that a physical spectrum be growing-mode dominated at `t_i`, for
the clean systems.

Three points remain open and deliberately unresolved here:
1. **Reproduction.** Paper/notebook reproduction keeps the legacy
   conventions, so the figures reproduce the published curves including
   their decaying transient.
2. **Barotropic runs.** These have no growing-mode convention and keep the
   legacy ICs. Supplying one would need a new, audited early-time model for
   the `k`- and D3-dependent solution.
3. **Amplitude.** The ΛCDM `qplus` recipe amplitude is unchanged. Its
   Timescape justification is outside F1.
